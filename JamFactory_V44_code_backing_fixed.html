논다이아토닉 코드

조성 밖의 코드를 활용해 긴장감과 색채를 더하는 대표적인 방법입니다.

이름 만드는 법 설명
Secondary Dominant세컨더리 도미넌트 ① 목표 코드의 근음에서 5도 위의 음을 찾습니다.
② 그 음을 근음으로 하는 Dominant 7th를 만듭니다.
③ 그 코드를 목표 코드 앞에 놓습니다.
예: D → 5도 위 A → A7 → D		 현재 조성의 다이아토닉 코드가 아닌 V7을 잠깐 빌려 특정 코드로 강하게 진행시키는 방법입니다. 목표 코드가 D라면 A7이 D의 V7이므로 A7 → D가 됩니다. 표기는 V7/x로 나타낼 수 있습니다.
Tritone Substitution트라이톤 서브 V7을 트라이톤 관계의 ♭II7로 대체
예: D♭7 → Cmaj7		 기존 V7과 같은 트라이톤을 포함하는 다른 도미넌트 7th를 사용해 해결합니다. 재즈에서 매우 자주 사용됩니다.
Modal Interchange모달 인터체인지 같은 으뜸음의 다른 모드에서 코드 차용
예: C Major → Cm, A♭, B♭		 현재 조성과 같은 으뜸음을 가진 다른 모드, 특히 평행단조에서 코드를 빌려옵니다. 익숙한 진행에 새로운 색깔을 더합니다.
Passing Chord패싱 코드 두 코드 사이에 연결 코드를 삽입
예: C → C♯dim7 → Dm		 목표 코드로 이동하는 사이에 코드를 넣어 베이스나 화음의 흐름을 부드럽게 만듭니다. 반음계적 감화음이 자주 사용됩니다.
Chromatic Chord크로매틱 코드 조성 밖의 음을 포함하는 코드 사용
예: C → D♭ → Dm		 다이아토닉 스케일 밖의 음이나 코드를 의도적으로 사용해 색채와 연결감을 만듭니다. 패싱 코드보다 넓은 개념입니다.
Diminished디미니시드 근음–♭3–♭5, 또는 dim7을 사용
예: C♯dim7 → Dm7		 불안정한 음정 구조를 이용해 강한 긴장감을 만듭니다. 특히 목표 코드로 반음 이동하는 연결과 도미넌트 대체에 유용합니다.
Augmented어그먼티드 메이저 트라이어드의 5음을 반음 올림
예: Caug = C–E–G♯		 증5도의 불안정한 간격으로 상승하는 듯한 긴장감을 만듭니다. 도미넌트와 연결 구간에서 색채를 더할 때 사용할 수 있습니다.
